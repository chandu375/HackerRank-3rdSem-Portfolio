## 1. Diagonal Difference

Calculates the absolute difference between the sums of the primary and secondary diagonals of a square matrix.

**Folder:** `Diagonal-Difference`

## 2. Dynamic Array

Uses dynamic sequences and the XOR operation to process queries and generate the required answers.

**Folder:** `Dynamic-Array`

## 3. Time Conversion

Converts a 12-hour AM/PM time format into 24-hour format.

**Folder:** `Time-Conversion`

## 4. Compare the Triplets

Compares the corresponding elements of Alice's and Bob's triplets and calculates their scores.

**Folder:** `Compare-the-Triplets`

## 5. Sparse Arrays

Uses a frequency map to count how many times each query string occurs in the given string list.

**Folder:** `Sparse-Arrays`

## Learning Reflection

Through these HackerRank problems, I learned how to approach algorithmic problems systematically and improve the efficiency of my solutions. I practiced working with arrays, vectors, strings, dynamic data structures, and hash maps. I learned that choosing an appropriate data structure can significantly reduce the time required to solve a problem. For example, Sparse Arrays can be solved efficiently using a frequency map instead of repeatedly comparing every query with every string. I also practiced analyzing time and space complexity and learned the difference between constant, linear, and combined linear complexity. Problems such as Diagonal Difference and Time Conversion helped me improve my implementation and logical thinking skills. Dynamic Array helped me understand how queries and dynamic sequences can be processed efficiently. Compare the Triplets strengthened my understanding of simple comparison and score tracking. Overall, solving these problems and maintaining them in GitHub helped me build a structured programming portfolio and improve my problem-solving skills.
